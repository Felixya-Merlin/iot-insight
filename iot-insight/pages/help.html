Help Center

Help the user to use this website

Everything you need to know to open the dashboard, import data, monitor devices, and understand your sensor workflow clearly and quickly.

1. Sign in

Use your account to access the dashboard and secure monitoring workspace.

2. Import data

Upload CSV files or connect your sensor sources from the Data Import screen.

3. Review insights

Open dashboards, alerts, reports, and analysis to understand device activity.

Use the Data Import page to upload CSV data or connect a ThingSpeak channel, preview the rows, and save the data to your workspace.

Provide your channel information and read API details on the import page, then validate the readings before saving the dataset.

Device and sensor readings are stored in Firebase to maintain reliable access, history, and dashboard performance.

Open the Dashboard or Analysis view, choose a parameter, and inspect trend changes over time.

An anomaly is a reading or pattern outside the normal expected range, helping you detect issues before they become major problems.

The Alerts page highlights unusual readings and threshold-based events so the right team can respond quickly.
